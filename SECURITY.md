# Security Policy

## Supported Versions

Security fixes are provided for the latest released version.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues. Use
[GitHub's private vulnerability reporting](https://github.com/{{github_username}}/{{project-name}}/security/advisories/new)
when enabled for this repository. Otherwise, contact the maintainers privately
through the email address listed in the repository profile.

Include the affected version, impact, reproduction steps, and any relevant
logs. Please allow maintainers reasonable time to investigate and coordinate
a fix before public disclosure.
